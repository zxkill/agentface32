# Code of Conduct

AgentFace32 follows a simple rule: contribute in a way that makes technical collaboration easier for everyone.

Be respectful, assume good faith, discuss code rather than people, and avoid harassment, discrimination, personal attacks, spam, or intentionally disruptive behavior. Maintainers may edit/remove content or restrict participation when necessary to keep the project constructive.

If a situation should not be handled publicly, use the repository owner's private contact channel or GitHub's private vulnerability reporting feature when the matter is security-related.
